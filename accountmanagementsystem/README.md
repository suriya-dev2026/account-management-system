# Account Management System

## Features

- User Registration
- Login with OTP
- JWT Authentication
- Refresh Token
- Spring Security
- PostgreSQL Database

## Technologies Used

 - Java
- Spring Boot
- Spring Security
- Maven
- PostgreSQL

## API Endpoints

### Register

POST /user/register

### Login

POST /user/login

### Verify OTP

POSt /user/verify/otp
